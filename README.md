# Derick Gary | IT Support Portfolio

Derick Gary’s IT support and technical operations portfolio website.

## Open the website

[https://jermaine2322.github.io/Portfolio/](https://jermaine2322.github.io/Portfolio/)

## Hosting

Static HTML and CSS, hosted with GitHub Pages from the main branch and repository root. No installation or build step is required.
